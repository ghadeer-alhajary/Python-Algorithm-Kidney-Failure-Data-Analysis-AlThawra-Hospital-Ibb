# 📊 تحليل بيانات الفشل الكلوي باستخدام خوارزمية بايثون - مستشفى الثورة العام (إب)
## Kidney Failure Data Analytics & Predictive AI Algorithm - Al-Thawra Hospital (Ibb)

---

## 🌍 نبذة عن المشروع (About The Project)
مشروع هندسي تطبيقي متكامل يجمع بين تحليل البيانات المتقدم (Advanced Data Analytics) والذكاء الاصطناعي (AI)، صُمم خصيصاً لتجهيز، تنظيف، وتحليل بيانات مرضى الفشل الكلوي بمستشفى الثورة العام بمحافظة إب - اليمن، والوصول بها إلى مرحلة التنبؤ بدقة عالية.

A Python-based data analytics and AI algorithm structured into four key phases. This project bridges the gap between advanced data analysis and artificial intelligence to reach high-accuracy predictive insights for kidney failure patients in Yemen.

---

## 🗂️ هيكلية المشروع والأقسام الأربعة (Project Architecture)

المشروع مقسم برمجياً ومنهجياً إلى أربعة أقسام أساسية متسلسلة داخل مجلد الخوارزميات (`Project-Algorithms`):

1. **Phase 1: Data Preprocessing and Cleaning Algorithm 🛠️**
   - خوارزمية مخصصة لتجهيز البيانات وتنظيفها جذرياً من القيم المفقودة والمتناقضة وإعدادها برمجياً.
2. **Phase 2: Primary Data Analysis Algorithm 📈**
   - إجراء التحليلات الأولية واستكشاف الأنماط الإحصائية الأساسية للبيانات.
3. **Phase 3: Secondary Data Analysis Algorithm 📊**
   - التحليلات المتقدمة واستخراج الارتباطات العميقة بين المتغيرات الطبية للمرضى.
4. **Phase 4: Model Building and Predictive Analytics 🤖**
   - بناء وتدريب نموذج التعلم الآلي (Machine Learning) للوصول إلى درجة التنبؤ الذكي الدقيق.

## 📂 محتويات المستودع (Repository Contents)
- **`Project-Algorithms/`**: يحتوي على ملفات الأكواد التفاعلية الأربعة بصيغة جوبيتر نوت بوك (`.ipynb`).
- **`Project-Datasets/`**: يحتوي على قواعد البيانات المقسمة بالمراحل (البيانات الخام من المستشفى، البيانات المدمجة، البيانات المنظفة، والبيانات الجاهزة للتعلم الآلي).
- **`Kidney-Failure-Theoretical-Section.pdf`**: التقرير والنص النظري الأكاديمي الشامل للمشروع المعتمد المسلم للجامعة.
